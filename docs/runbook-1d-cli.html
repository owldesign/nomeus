!Troubleshooting

ini --fpm: Not found — Valet only writes php-fpm.d/valet-fpm.conf for versions it has used or isolated. devkit isolate php@8.3 --site=smoke then devkit unisolate --site=smoke creates it.
db: "Unable to find application named TablePlus" — the cask installed under a different name or isn't installed. ls /Applications | grep -i table; then devkit config:set db_client <name> — an unknown value is passed to open -a verbatim.
db opens the wrong app — open -a TablePlus mysql://… is explicit, so this can't be the default-handler problem; it means db_client is set to something else. devkit config:get db_client.
edit/ini opens nothing, no error — the URL scheme is registered to an app that isn't running and macOS dropped it silently (PhpStorm via Toolbox does this once in a while). Launch the IDE once and retry.
