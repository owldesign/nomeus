!Troubleshooting

doctor: "check crashed: …" — a section threw instead of reporting; the message names it. The other sections still ran. Paste it — a crash in a check is a bug in the check.
self-update: "git fetch failed" — the upstream isn't reachable (VPN, credentials). --no-git refreshes deps, build and ini without it.
Dashboard doesn't come back after "update devkit" — the build failed mid-task: Tasks page → the self-update task's log. npm run build by hand shows the error; the old bundle is gone, so until it builds the dashboard is blank.
install --check says "todo" for something that's clearly there — the check tests a specific path (listed in docs/layout.md); a custom location (different code dir, brew prefix) needs the matching env override.
