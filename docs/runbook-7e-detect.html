2Pick your everyday mode

Both are "quiet until you want it". detect: zero cost when the IDE is closed, but every request connects while it listens (the dashboard's polls included — 5b's PhpStorm settings still apply) and each toggle restarts fpm. trigger: always loaded, never restarts, starts only when asked. Most people end up on trigger; detect is for the "I never want to think about it" crowd.

!Troubleshooting

Mode never flips — tail ~/.nomeus/php/xdebug-detect.log. Empty: the watcher isn't running (doctor names it). "no version in detect mode — exiting": the state was changed by another mode; nomeus xdebug:mode detect. PhpStorm listening on a port other than 9003: nomeus config:set xdebug.port <port> then set detect again.
Flips, but the breakpoint doesn't hit — 5b's items: path mapping for the server, the "force break" settings, the registered server name.
Watcher crash-loops (launchctl shows exits) — the log's last lines; usually php-fpm failing to come back within 15 s (valet restart php by hand shows why).
