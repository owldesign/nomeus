Nomeus

νομεύς, shepherd — Herd Pro, without the subscription. On Laravel Valet and Homebrew, for macOS.

curl -fsSL https://nomeus.dev/install | bash

Needs Xcode Command Line Tools and Homebrew. Clones github.com/owldesign/nomeus to ~/.nomeus/app, installs the Brewfile, Valet, the dashboard, and ends with nomeus doctor. Re-running is a no-op.

Sites, PHP versions, isolation, TLSValet, through nomeus sites / php:* and the dashboard
ServicesPostgres, MySQL, MariaDB, Redis, Meilisearch, Typesense, SeaweedFS (S3) — multiple instances, clone, adopt from brew services
Maila Mailpit instance, one inbox per app
herd init / herd.ymlnomeus init / nomeus.yml, and nomeus new
Log viewerevery site's logs, nginx, php-fpm; file:line into your IDE
Dumpsdump()/dd(), queries, jobs, views, requests, logs — no package needed for dumps
Xdebugper PHP version: off / on / trigger

What it is not

No menubar app (PHP Monitor is recommended), no Windows or Linux yet, no support contract. It costs nothing: MIT.
