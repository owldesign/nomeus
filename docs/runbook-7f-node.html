!Troubleshooting

nomeus node: "fnm is not installed" — it looks at /opt/homebrew/bin/fnm then PATH. brew install fnm.
fnm install fails for a bare major (e.g. 22) — fnm resolves majors fine; a failure is usually the network or a not-yet-released version. fnm ls-remote | tail shows what exists.
post-init script: "fnm: version 22 is not installed" — the node step comes before scripts, so this means the node step was skipped because fnm wasn't found at plan time; run nomeus node:install 22 and re-init.
Terminal's node doesn't change when I cd — the shell line is missing or the terminal predates it: eval "$(fnm env --use-on-cd --shell zsh)" in ~/.zshrc, new terminal.
