!Known unknowns (things I expect the first run to surface)

valet-linux-plus package name — the installer uses genesisweb/valet-linux-plus; the project moved orgs. If composer can't find it: NOMEUS_VALET_PACKAGE=valet-linux-plus/valet-linux-plus curl … | bash, or the ahmdadl/valet-linux-plus fork.
valet install on Ubuntu 24.04 and systemd-resolved — dnsmasq and resolved both want :53; valet-linux-plus handles it in recent versions, older ones need /etc/systemd/resolved.conf tweaks. The log tells.
valet trust missing — the installer warns and continues; dashboard actions that sudo will fail until it's there. valet-linux-plus has it in 1.7+.
fpm socket names — the PPA's /run/php/php8.4-fpm.sock is what nomeus checks; valet-linux-plus also writes its own ~/.config/valet/valet.sock. If the doctor says "no php-fpm socket answers" while nginx serves fine, paste ls -l /run/php/.
Linuxbrew formulas building from source — arm64 Linux lacks bottles for some; x86_64 VMs have them. postgres from source is ~10 min.
