!Troubleshooting

Anything on the Mac behaves differently after the overlay — it shouldn't; nomeus doctor then the specific command with the failure. The binding is in AppServiceProvider: ProcessManager → LaunchdManager when Platform::isMac().
Homebrew on the VM: "Cannot install in Homebrew on ARM"/"unsupported" — the VM must be x86_64 or arm64 Ubuntu 22.04+; Homebrew supports both on Linux, but not every formula has bottles for arm64 Linux (it will build from source — slower, still works).
