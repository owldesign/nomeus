1Status and Services ~6 min

open https://nomeus.test
the strip is a darker bezel: lantern star · php 8.4 in lantern · valet version · four steady green stars · "svc 11/11" · a slow-pulsing polling dot at the right
Status: sans headings and uppercase labels, mono values; "update nomeus" is the one primary (lantern) button; the doctor panel has OK/WARN/FAIL chips and, under every non-OK row, "fix: $ nomeus …  [run fix]"
open https://nomeus.test/services
36px rows, mono 12.5; each instance a steady green star; hover washes the row; click a row → the well drops to inset with .env (keys dim, values mid) and the log tail with a blinking lantern caret
click "stop" on redis → the task frame appears in the row (lantern border, marching stripe, streaming log, elapsed) → then the row goes faint with a hollow star and a green "start"
click "start" → during the seconds before redis answers the star pulses amber (starting) → steady green
click "delete" on any row → the button swaps in place for a fail-tinted frame: "delete redis?" · keep data · no · [delete]; press Esc → back. Don't confirm.
Crash-looping (the flickering red star with "crash · exit N" in the pid cell) is the state you saw in 2a when postgres lacked LC_ALL. Nothing on your machine does that now; a way to see it safely: nomeus services:create redis --name=tmp --port=6390 --no-start, then echo "port 99999" >> ~/.nomeus/services/tmp/conf/redis.conf, nomeus services:start tmp (it will fail to start and launchd will keep trying), watch the row, then nomeus services:delete tmp.
nomeus xdebug:mode on --no-restart && open https://nomeus.test
the doctor gains a WARN row (xdebug on, nothing listening) with "fix: $ nomeus xdebug:mode trigger --php=8.4 [run fix]" → click run fix → a compact task frame, then the row disappears on the next re-check
"run fix" only accepts commands the doctor itself prints, from an allow-list of idempotent ones (ini, xdebug, extensions, node, service start/restart, secure, link, mail). rm, services:delete, self-update, migrate are refused with a 422 — the terminal is the place for those.

!Troubleshooting

Fonts don't change (still the system monospace) — the woff2 files must be served from /fonts/…: curl -sk https://nomeus.test/fonts/GeistMono-Variable.woff2 -o /dev/null -w '%{http_code}' → 200. Valet serves public/ directly, so a 404 means the overlay didn't land in public/fonts.
Build error mentioning oklch or /13 opacity — needs Tailwind v4 (opacity modifiers on arbitrary values and oklch tokens). npm ls tailwindcss.
Stars render as squares — an SVG path inside a table cell with display:none parents can size to 0 in Safari; the component sets explicit width/height, so this means a CSS conflict — paste the page.
