!Troubleshooting

helper: "sudo: a password is required" — the sudoers file isn't in place, has the wrong user, or the wrong mode (must be 0440). sudo visudo -cf /etc/sudoers.d/nomeus; the user must match $USER.
AptPhp lists no versions — it needs both /etc/php/X.Y and /usr/bin/phpX.Y; the PPA's phpX.Y-cli package provides the latter.
The Mac's doctor or xdebug table changed after the overlay — it shouldn't; paste it. The provider binding is in AppServiceProvider: PhpProvider → BrewBridge when Platform::isMac().
