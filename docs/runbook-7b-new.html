!Troubleshooting

"No parked directory — pass --dir" — Valet has no parked path (only linked sites). --dir=~/Sites/shop works; init links it.
composer create-project fails on a name — the package or constraint doesn't exist (--from=vendor/pkg:^x). Nothing was created; fix the flag and re-run.
init stops at db:pg17 "role postgres does not exist" — an adopted cluster without the role; runbook 3b's troubleshooting has the one-liner.
Dashboard form: task fails immediately with "already exists" — a site of that name is parked or linked; the CLI's --empty is the only way to init an existing one, on purpose.
