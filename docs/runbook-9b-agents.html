!Troubleshooting

doctor says the agent is stale but agents:rewrite prints "✓ runs this app" — two different apps: the doctor ran under the dashboard (~/.nomeus/app?) and the CLI from ~/Code/nomeus. nomeus status --json | grep -A1 version and readlink $(brew --prefix)/bin/nomeus — decide which checkout is "the app" and point the other at it.
The xdebug-detect row appears stale right after enabling detect — XdebugWatcher::enable() writes Shell::phpBin(), and if <brew>/bin/php was relinked since, the file and today's value differ; agents:rewrite is the fix, and it's the correct verdict.
