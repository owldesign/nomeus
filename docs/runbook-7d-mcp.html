!Troubleshooting

Claude Desktop: "nomeus" missing or "server disconnected" — Claude's log (~/Library/Logs/Claude/mcp-server-nomeus.log) shows what nomeus printed. Usually the shim path: the config must name /opt/homebrew/bin/nomeus (or the full path to bin/nomeus), since Claude Desktop's PATH is not your shell's.
Claude Desktop: works, then "Server transport closed unexpectedly" a minute after the last call — the client hands the process a socketpair, and PHP's default_socket_timeout (60 s) made an idle STDIN look like EOF. Fixed in 1.4.0: idle is not EOF. If you see it, you're on an older build.
A tool returns "Internal error: …" — a PHP exception inside the handler; nomeus mcp --call=<tool> --args='…' reproduces it in the terminal with the full message.
Claude sees the tools but calls nothing — the client sends initialize with a protocol version nomeus doesn't know; nomeus answers with its own (2025-06-18) and current clients accept that. Older clients may need the 2024-11-05 shape — paste the log line.
