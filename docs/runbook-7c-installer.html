!Troubleshooting

Spinner never stops on "Brewfile" — brew is asking something on a hidden tty (a cask needing a password). tail -f ~/.nomeus/install.log in another window shows it; Ctrl-C and re-run with --verbose.
php:ext: "brew search shivammathur/extensions/redis lists what exists" — the tap has no build for that PHP yet (usually a brand-new minor); pick the PHP the site actually runs.
nomeus.dev/install returns 404 after enabling Pages — Pages builds take a minute; the CNAME file must be in site/ (it is); DNS propagation can take longer than the Pages check.
rm: "dropdb … role postgres does not exist" — same adopted-cluster role issue as 3b; the directory was still removed, drop the database by hand as your user.
