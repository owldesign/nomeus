!Troubleshooting

pest on CI: "Test resolved BrewBridge on the real prefix /opt/homebrew" — impossible on ubuntu (no /opt/homebrew/bin/brew), so if you see it locally it's a test that stopped setting nomeus.config_path; the guard is doing its job.
"Your lock file does not contain a compatible set of packages" on CI — the matrix PHP is below what the lock resolves (Symfony 8 → 8.4.1). The matrix and composer.json's floor must both say what the lock says.
"The lock file is not up to date with the latest changes in composer.json" — a warning after the floor change; composer update --lock rewrites the content-hash and nothing else.
"dashboard build" fails on npm ci — package-lock.json out of sync with package.json; npm install locally, commit the lock.
"dashboard build" fails on the manifest check — vite wrote somewhere other than public/build; check vite.config.ts build.outDir — self-update assumes the same path.
release job: "Resource not accessible by integration" — Settings → Actions → General → Workflow permissions → "Read and write". release.yml asks for contents: write but the repo default can override it.
docs:changelog: "no tags found" — a shallow clone (git fetch --tags --unshallow), or tags not fetched (git fetch --tags). CI's docs job checks out with fetch-depth: 0 for this reason.
Unreleased shows commits you'd already tagged — the tag is lightweight and older than the branch tip you think; git describe --tags tells you what HEAD is relative to.
